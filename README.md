Forecasts each GTA VI trophy's Exophase earn rate at 2026-11-26 as five quantiles, from the house's launch-week reads: earners and players-tracked are fit separately on log-time curves and recombined, with a dilution prior when the history is a single snapshot.

## Run it

```sh
python3 main.py
```
